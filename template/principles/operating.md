# Operating principles

Rules that apply to everything, inherited by every SOP and skill.

- **Verify before you claim.** "Done" means run, checked and shown. A claim
  without evidence is a guess wearing a suit.
- **Date your changes.** Every rule and artifact carries a date and a reason.
  Undated guidance cannot be trusted to still apply.
- **Cheap first.** Reach for the simplest fix that holds. Complexity is a
  cost someone pays later.
- **Plain language.** Write so a careful second-language reader can follow.
  No jargon where a plain word does the job.
- **Reversible over clever.** Prefer the action you can undo. Irreversible
  acts get explicit owner approval first.
- **Leave it better.** Every session should leave the ethos, the repo, or
  the documentation slightly more useful than it found it.
