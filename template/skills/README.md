# Skills

Shared skills live here, one directory per skill, each with its own `SKILL.md`.

- Each skill keeps its own credit and license. Do not strip either.
- A skill here is the version your agents load, not a draft. Drafts belong in
  your notes until they prove themselves.
- If a skill stops matching reality, fix it in the same change that proves
  the mismatch, and date the fix.
