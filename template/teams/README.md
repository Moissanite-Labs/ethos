# Teams

Rules that apply to one team or family of agents only. One file per family,
named for the family (`exo.md`, `hermes.md`, ...).

Team files add to the shared rules in `principles/` and `sops/`. Where a
team file conflicts with a shared rule, the shared rule wins until the owner
writes down the exception and why.

Keep each file dated, and keep it honest: what the family actually does now,
not what it was planned to do.
